# 0002. 公開方針は「GitHub 公開まで」とする

- Status: Accepted
- Date: 2026-09-24

## Context
プロジェクト開始時に、公開方針（誰に見せるか・継続利用するか・運用コスト・公開可否）を決めておく必要があった。

- 見せたい相手: 就職・転職活動でアピールしたい
- 継続利用: 学習目的で作って終わり（常時稼働のデモは不要）
- 運用コスト: 無料枠のみ

## Decision
公開方針は「GitHub 公開まで」とする。コードと README が読める状態を目指し、常時稼働のデモ URL は用意しない。

現在リポジトリは Private で作成しているが、実装が一定形になった段階で Public に切り替える。

データソース選定（Issue #10）の結果、利用する外部 API の規約上公開が難しい場合は、この方針を見直す。

## Consequences
- デモ URL のホスティングコストや運用の手間は発生しない
- 就職・転職活動でのアピールには、README とコードの読みやすさが特に重要になる
- 外部 API（地図・Spotify 等）を採用する場合、利用規約次第でこの方針の再検討が必要になる可能性がある
